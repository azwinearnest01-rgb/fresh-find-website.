# FreshFind 🌿

A responsive farmers-market directory for discovering local growers, seasonal produce, and community markets.

## Features

- Search and filter markets by area and produce type
- Browse a seasonal produce guide
- Save bookmarks and personal notes in the browser
- Use browser geolocation to jump to nearby-market results
- Responsive desktop and mobile navigation
- Built-in guided help and accessible toast notifications

## Technology

- HTML5
- CSS3
- Vanilla JavaScript
- Tailwind CSS via CDN
- Font Awesome
- Browser Local Storage and Geolocation APIs

## Run locally

Open `index.html` in a modern browser. No build step is required.

## Demo limitations

FreshFind is currently a front-end demonstration. Authentication, contact submission, social sharing, visitor counts, and market records are simulated or stored locally; no production backend is connected yet.
